# Riichi Trainer

Mahjong riichi trainer that helps you excerice several abilities

## Project motivation

https://github.com/Euophrys/Riichi-Trainer is already a good resource for training, but it lacks some features and it doesn't look maintained anymore.

Here are a list of problem that this trainer aims to solve

1. the interface is not responsive, really hard to use on phone
2. settings interface looks clunky
3. the efficiency trainer allows you to load a specific hand, but not the wall (or the river). This means that it's not possible to recreate specific situations
4. the efficiency trainer shows you the ukeire for your choice and the best choice, but it would be useful to actually see the tiles that improves your hand (yes, there is the tenhou link, but it's not really great from the UX experience)
5. the shanten trainer number input doesn't submit on enter
6. the timer on the shanten trainer only starts on the first guess, it would be nicer showing concealed tiles + play pause button
7. having something like https://scoringtrainer.konbamwa.net/ integreated inside the same webapp
