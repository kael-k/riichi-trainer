  <action>
Create `src/features/table/useTableRound.ts`.

Types, with `onUserDraw`/`onUserDiscard`/`onAgariCall` named verbatim (these are the user's own
names, not placeholders):

- `export interface TableRoundInput { wall: ParsedTile[]; players: number; seatIndex: number; options: MatchOptions; replay?: ParsedTile[]; stopAtTenpai?: boolean; onUserDraw?: (ctx: UserDrawContext) => void; onUserDiscard?: (tile: ParsedTile, stats: DiscardStats) => void; onAgariCall?: AgariCall }`
- `export interface UserDrawContext { turn: number; drawn: ParsedTile | undefined; analysis: TableAnalysis }`
- `export interface DiscardStats { kind: 'discard' | 'kita' | 'kan'; analysis: TableAnalysis; readonly yours: DiscardOption; readonly best: DiscardOption; readonly danger: TileDanger | undefined }` — `yours`, `best` and `danger` are getters that read off `analysis`, so a consumer that only wants tiers never triggers the ukeire ranking and one that only wants ukeire never triggers the danger assessment.
- `export type AgariCall = (win: WinRecord) => void`

Hook body, following `useEfficiencyRound`'s established shape: mutable `TableCore` in a
`useRef`, a `TableSnapshot` mirrored into `useState`, a `restartCount` state used only as an effect
trigger, and the "reset while rendering" guard keyed on `input.wall` identity (document that the
caller must hand in an identity-stable `wall`/`options`, which `useUrlData`'s per-navigation
memoisation already provides).

Build: `createMatch(input.wall, input.players, input.options)` into a `TableCore`, then
`goRound(core)` so the seats before yours act, then `beginTurn`. Replay: set a
`replaying` ref true, run `replayDiscards(core, input.replay ?? [], step)` where `step` is the same
advance function `discard` uses, then set it false. Every callback invocation is guarded on
`!replaying.current` — that is D-06's suppression, and it must wrap `onUserDraw`, `onUserDiscard`
and `onAgariCall` alike. Do not move the log-writing `useRef` identity guard in here; that stays in
each consuming trainer, because what gets _logged_ is a trainer's concern and the guard is a React
commit-time concern (see RESEARCH Pitfall 4).

`fireDraw()`: when the match has not ended and your seat holds 14 tiles, compute
`analysisOf(core)` once, stash it in a `drawAnalysis` ref, and call `onUserDraw({ turn, drawn, analysis })`.
`discard(index)`: resolve the tile from the snapshot's `hand`/`drawn` exactly as
`useEfficiencyRound.discard` does today; build `DiscardStats` from the **stashed** `drawAnalysis`
ref (never a fresh `analysisOf` call — the hand is about to be 13 tiles and would rank
differently); fire `onUserDiscard`; then advance: `finishTurn(match, options, tile)`, stop when
`stopAtTenpai` and `shanten(hand) <= 0`, else `goRound(core)`, then `beginTurn` when the wall still
has tiles and the hand has not ended; then `fireDraw()`. After each advance, when `match.win` is
newly set, fire `onAgariCall(match.win)`.

`kita()` and `kan(id)`: port the board mutations from `useEfficiencyRound.kita`/`kan` verbatim
(remove tile, push `nuki`/`melds`, bump `visible`, flip the next dora indicator for a kan,
`drawReplacement`), but emit them through `onUserDiscard` with `stats.kind` set to `'kita'`/`'kan'`
and `stats.yours` resolved from the stashed analysis (the `NORTH` entry for kita, the matching
`evaluateKan` entry for a kan). Then `fireDraw()` for the replacement.

`restart()`: bump `restartCount`; the effect rebuilds with `wall: []`, which deals a fresh random
board.

Return `{ ...snapshot, discard, kita, kan, restart, replaying: replaying.current, situation() }`
where `situation()` returns a `Situation` carrying `wall: core.match.wall` and
`river: yourDiscards(core)` plus the round/seat/flags, ready for `encodeSituation`.

Create `src/features/table/useTableRound.test.ts` with `renderHook`/`act` from
`@testing-library/react`, one case per `<behavior>` bullet, using `vi.fn()` callbacks and
deterministic walls built with `wallWithHand`/`completeWall`.
