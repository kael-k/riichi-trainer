<objective>
Replace the seed-plus-`Pinned`-prefix board record with an explicit, validated wall in draw order,
so a board can be shared, hand-authored and reproduced exactly (REQ-02, D-09 through D-12).

Purpose: every other plan in this phase builds on `createMatch`'s new wall-taking shape — the
shared stepper, the split trainers, the folding migration and the lab all deal from it. It also
inverts the riskiest semantic in the codebase (today a wall prefix is drawn _after_ the deal;
under the new format its leading segment _is_ the deal), so it lands first and is proved
end-to-end before anything is built on top.

Output: `core/wall.ts` gains wall completion/validation; `createMatch` takes a `ParsedTile[]` wall;
`Situation` carries that wall instead of a seed and a pinned hand.
</objective>

| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| shared link -> app | The `wall=`/`river=` query params are attacker-controllable: anyone can hand a crafted URL to a player. Nothing else in this SPA crosses a trust boundary — no backend, no auth, no server-side state. |
