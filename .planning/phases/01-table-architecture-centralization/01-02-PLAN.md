<objective>
Extract the turn-stepping, visibility, snapshot, replay and per-turn analysis that
`useEfficiencyRound.ts` and `useFoldingRound.ts` each reimplement into one pure, React-free

this phase — the two efficiency apps, the lab, folding's own hook and scoring — composes these
primitives instead of writing its own.

exported canonical one.

  <action>
In `src/core/match.ts`, export the existing module-private `seenBy(state, player)` and change its
body to `seen[i] = Math.min(TILES_PER_KIND, state.visible[i] + player.hand.counts[i])`, importing
`TILES_PER_KIND` from `./wall` (already imported for `DEAD_WALL_SIZE`/`INITIAL_HAND_SIZE`).
Document the cap as a safety net: face-up tiles and your own hand are disjoint sets, so the sum
cannot legitimately exceed four copies, and clamping means a future bookkeeping slip degrades an
ukeire count instead of proposing a fifth copy. Keeping it here rather than in `table.ts` avoids a
circular import — `table.ts` imports the stepper from `match.ts`, so `match.ts` must not import
back.

Create `src/core/table.ts` with a file-level doc comment stating it is pure and React-free, that it
holds the stepping/visibility/snapshot/replay primitives every trainer shares, and that grading
stays with each consumer.

Export `interface TableCore { match: MatchState; options: MatchOptions; seatIndex: number }` — the
same three-field shape both hooks already call `RoundCore`.

Export `seenBy(core: TableCore): Uint8Array` as a thin wrapper over `match.ts`'s exported
`seenBy(core.match, core.match.players[core.seatIndex])`.

Export `goRound(core: TableCore): void` implementing the loop both hooks share verbatim:
`for (let guard = 0; guard < 8 && core.match.seat !== core.seatIndex && !core.match.ended; guard++) { beginTurn(core.match, core.options); finishTurn(core.match, core.options) }`.
Keep the "one full go-round is the bound; a call hands the turn sideways but never backwards"
rationale in the comment. It carries no opponents-on/off branch and no next-draw: each consumer
layers its own stop condition and its own `beginTurn` on top (efficiency stops at tenpai, folding
stops when the hand ends).

Export `yourDiscards(core: TableCore, from = 0): ParsedTile[]` reading `core.match.discards`
filtered to `core.seatIndex`, sliced from `from`, mapped to `{ id, red }`. Keep the reason in the
comment: a claimed discard is popped out of the river but stays in `discards`, so a replay built
off the river would arrive at a different board.

`export interface TableAnalysis { readonly seen: Uint8Array; readonly ranked: DiscardOption[]; readonly danger: TileDanger[] }`

`export function analysisOf(core: TableCore): TableAnalysis` returning an object whose three
members are getters backed by closure variables computed on first read and cached thereafter.
`seen` calls `seenBy(core)`; `ranked` calls `evaluateDiscards(player.hand, seen, core.options.sanma)`;
`danger` calls `assessDiscards(player.hand, threatViews(core.match), seen, core.options.sanma)`.

Document why this is lazy rather than eager (D-05): the solitaire trainer never reads danger, the
folding trainer never reads ukeire, and `evaluateDiscards` costs roughly 476 shanten probes per
turn — nobody should pay for analysis they do not read. Document the second half of the contract
too: an analysis object is a snapshot of one moment, so a consumer captures it at draw time and
hands the _same_ object to its discard grading, which is what stops the numbers being recomputed
against an already-13-tile hand after the throw.
